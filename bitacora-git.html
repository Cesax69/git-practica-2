Parte 1 — Repositorio Local
Carpeta: practica-taller-git/
01 Inicializar el repositorio
practica-taller-git
$ git init
Initialized empty Git repository in C:/Users/cesar/Downloads/practica/practica-taller-git/.git/
¿Qué hizo este comando? Creó la carpeta oculta .git/ dentro del directorio. A partir de ahora Git rastreará todos los cambios de esta carpeta. Este es el "cerebro" del repositorio local.
02 Crear index.html y comprobar estado
practica-taller-git — git status
$git status
On branch master No commits yet Untracked files: (use "git add <file>..." to include in what will be committed) index.html nothing added to commit but untracked files present (use "git add" to track)
Git detecta index.html como fichero no rastreado (untracked). Existe en el directorio pero Git aún no lo conoce — no está en ningún commit ni en el stage.
03 git add + primer commit
practica-taller-git — git add & commit
$git add index.html
# Sin salida — el fichero pasó al Staging Area

$git commit -m "agregar fichero index.html inicial"
[master (root-commit) 663da4d] agregar fichero index.html inicial 1 file changed, 13 insertions(+) create mode 100644 index.html
04 Añadir description.html + modificar index.html
practica-taller-git — git status + git diff
$git status
On branch master Changes not staged for commit: (use "git add <file>..." to update what will be committed) modified: index.html Untracked files: description.html no changes added to commit

$git diff
diff --git a/index.html b/index.html --- a/index.html +++ b/index.html @@ -9,5 +9,14 @@ <h1>Taller Git - Práctica 2</h1> <p>Bienvenido a mi proyecto de práctica de control de versiones con Git.</p> <p>Autor: César Enrique Garay García</p> + <nav> + <ul> + <li><a href="index.html">Inicio</a></li> + <li><a href="description.html">Descripción del Proyecto</a></li> + </ul> + </nav> + <footer> + <p>Taller Git &mdash; 2026</p> + </footer>
git status muestra que index.html fue modificado (modified — en amarillo) y que description.html es un nuevo fichero sin rastrear (untracked — en rojo). git diff muestra exactamente qué líneas cambiaron dentro de index.html: las verdes son añadidos.
05 Crear TODO.txt — Git lo detecta
practica-taller-git — TODO.txt detectado
$git status
On branch master Changes not staged for commit: modified: index.html Untracked files: TODO.txt description.html no changes added to commit
Git detecta el TODO.txt pero todavía no lo hemos ignorado. Aparece en rojo como untracked.
06 Crear .gitignore — TODO.txt desaparece
practica-taller-git — .gitignore activo
$git status
On branch master Changes not staged for commit: modified: index.html Untracked files: .gitignore description.html no changes added to commit
✅ TODO.txt ya no aparece. Al crear el fichero .gitignore con la línea TODO.txt, Git dejó de rastrear ese fichero. El propio .gitignore sí aparece como untracked — ¡es necesario añadirlo al repositorio para que funcione en otros equipos!
